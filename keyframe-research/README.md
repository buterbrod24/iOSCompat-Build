# Keyframe scalar timeline research

Apple KeyframeTimeline https://developer.apple.com/documentation/swiftui/keyframetimeline and WWDC23 https://developer.apple.com/videos/play/wwdc2023/10157/ describe time sampling, instantaneous moves and independent tracks. Independent scalar implementation supports linear, instant and explicit-velocity cubic Hermite segments, clamped times and multiple Double tracks. It deliberately omits springs, implicit velocity selection, custom timing curves, arbitrary Animatable values, trigger/repeat scheduling, rendering and phase animation. Twelve mathematical and state controls and nine independently sampled native linear comparisons are scheduled in CI. Native comparisons are on macOS, not an iOS device. No claim that explicit Hermite segments reproduce Apple's CubicKeyframe defaults. No native types, protocol identity or binary aliases. The native comparison tests public API only.
