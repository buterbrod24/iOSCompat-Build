# Phase sequencing and completion research

Apple PhaseAnimator https://developer.apple.com/documentation/swiftui/phaseanimator and WWDC23 https://developer.apple.com/videos/play/wwdc2023/10157/ describe sequential animated phases and trigger-based/repeating forms. Apple AnimationCompletionCriteria https://developer.apple.com/documentation/swiftui/animationcompletioncriteria distinguishes logical completion from actual removal; Transaction.addAnimationCompletion https://developer.apple.com/documentation/swiftui/transaction/addanimationcompletion(criteria:_:) promises exactly-once completion and immediate completion when no animations are created. The independent phase sequencer only accepts explicit acknowledgments from a cooperating driver. Unique step tokens reject stale or duplicate notifications; cancellation invalidates pending steps. Local policy: one-shot returns to phase zero, repeated trigger values are ignored, distinct triggers reset to phase zero and request the next phase; singleton sequences are inert. Native trigger interruption semantics are not claimed. No timer approximation, actual SwiftUI completion observer, native ABI substitution, rendering proof or device result. Fifteen deterministic checks and independent SDK import observations scheduled. Future driver must define completion semantics explicitly.
