# Legacy content unavailable component

Apple documents UIContentUnavailableView and UIContentUnavailableConfiguration as placeholder content managed by a view or controller: https://developer.apple.com/documentation/uikit/uicontentunavailableview and https://developer.apple.com/documentation/uikit/uicontentunavailableconfiguration-swift.struct . An independent opt-in implementation uses public legacy UIKit labels, image view, scrolling layout, activity indicator and button. Empty/loading/retry states, dynamic type, action replacement, removal and recreation are covered by ten simulator controls. This does not claim pixel parity, native class or Swift ABI identity, automatic controller state updates or compatibility with existing compiled apps. No runtime injection. Layout and accessibility require real-device validation. The separate UIAction selectedImage feature is a selection indicator (WWDC23 https://developer.apple.com/videos/play/wwdc2023/10055/); mapping it to the ordinary action image is not equivalent and is deferred.
