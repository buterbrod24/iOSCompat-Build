Independent ARM64 object built using the original SDK with iOS 16.2 deployment target and iOS 17 availability annotations on its test entry and model. This static experiment does not call the entry on any device. The unmodified object is linked separately against the research library, with strict direct dependency, export and provider checks. No system SDK files or third-party binaries are changed; only text evidence is published. Failure of full required-name coverage must be investigated before a device probe is built.
