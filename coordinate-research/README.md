# Typed coordinate spaces

Apple CoordinateSpaceProtocol documentation distinguishes local/global/explicitly named spaces from the nearest scrolling ancestor: https://developer.apple.com/documentation/swiftui/coordinatespaceprotocol and https://developer.apple.com/documentation/swiftui/coordinatespaceprotocol/scrollview(axis:) . The Swift ABI metadata specification https://github.com/swiftlang/swift/blob/main/docs/ABI/TypeMetadata.rst distinguishes nominal identities, conformances and generic metadata. Stock.swift is an original independent client compiled against the modern SDK for iOS 17; Adapter.swift uses only legacy iOS 16.2 APIs and an independent protocol. The CI compares exact stock function/opaque descriptor imports and checks that legacy code does not import identified modern types. Compiler IR call-shape evidence is retained as text, not a proof of interchangeable functions. Six controls check enum conversion and generic view construction, not actual geometry, scroll behavior or gestures. Automatic nearest scrolling-ancestor discovery is not implemented; clients explicitly name owners. No native aliases, witness changes, or third-party binaries.
