# UIKit legacy trait observer

Apple's documentation (https://developer.apple.com/documentation/uikit/adapting-your-app-when-traits-change and https://developer.apple.com/videos/play/wwdc2023/10057/) distinguishes broad legacy traitCollectionDidChange from selective iOS 17 registration. This original source-level adapter filters five legacy traits, preserves old/current collections, uses explicit tokens and FIFO delivery for nested changes, and skips initial nil previous state. Callbacks execute on MainActor, may unregister, and newly registered callbacks do not receive the current event. Owners should unregister or capture weakly to avoid retain cycles. These are explicit local semantics, not an assertion of Apple's callback ordering. The view subclass forwards legacy notifications; simulator controls use manually constructed trait collections, not a live hierarchy. No native protocol, existential, trait override layout, binary import alias, swizzling or system patch. A modern UIAction selectedImage has different rendering semantics; no silent approximation is approved.
