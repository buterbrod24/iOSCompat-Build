# Witness control header research

Compared TargetGenericWitnessTable and TargetResilientWitness in [Swift 5.7 Metadata.h](https://github.com/swiftlang/swift/blob/swift-5.7-RELEASE/include/swift/ABI/Metadata.h) and [Swift 5.9 Metadata.h](https://github.com/swiftlang/swift/blob/ea95594ae137f288bf29a0b489b8689680a0086a/include/swift/ABI/Metadata.h). The inspected declarations match in field structure. This is not a runtime behavior equivalence claim. Swift 5.9 TargetProtocolConformanceDescriptor has trailing retroactive context, conditional requirements, conditional pack descriptors, resilient header and records, and generic witness control. Read fixed header fields only with bounds derived from file-backed readonly text and observed neighboring record starts. Skip pointer-bearing arrays without interpreting payloads. Generic control is 12 bytes: two uint16 fields and two relative fields. Report template size, private word count and the low instantiation bit; the source explicitly warns that this bit is not meaningful in current compiler practice. No function addresses resolved, no actual witness table inspected, no metadata creation, no authentication changes. Six synthetic tests and extended compiler fixture assertion. Previous generic pack run 46053173477 observed one metadata pack in the unconstrained fixture, and one metadata plus one witness pack in the constrained fixture. Device and third-party binary compatibility remain unverified.
