# Shared cache research, phase 1

Apple describes split shared cache mappings in https://github.com/apple-oss-distributions/dyld/blob/main/doc/CacheLayout.md and header fields in https://github.com/apple-oss-distributions/dyld/blob/main/include/mach-o/dyld_cache_format.h . DyldSharedCache.cpp selects legacy or modern image tables based on header extent. The standalone cache_inventory tool reads bounded regions, never maps an entire multi-gigabyte file into memory, and reports architecture, UUID, declared platform/OS version, mapping extents, image paths and whether their unslid addresses belong to a mapping in the supplied file. Subcache count is declarative; actual UUID/suffix matching is not implemented. A remote image is not an absent image. No export absence inference, cache extraction, pointer fixups, loader changes, firmware publication or system replacement. The header offsets are based on the cited layout and tested on synthetic fixtures only. Next validate against a locally supplied original iOS 16.2 cache and compare with https://github.com/blacktop/ipsw (ipsw dyld info). Apple's extractor may omit trie information; standalone Mach-O graph results cannot replace original cache evidence.
