# Selected-export audit coverage

Run locally: `python3 scripts/audit_coverage.py path/to/local-symbol-audit.txt`. The input format is the existing selected-export report with declared totals, `SYMBOL DETAILS`, provider/strength/raw Mach-O name records and indented consumers. The parser validates row/consumer/strong totals, rejects duplicates, normalizes exactly one Mach-O underscore and requires provider identity for catalog matches. Aggregate counts are printed by default; `--details` includes exact matched names. No audit, original app, private report, or consumer paths are uploaded. Tests use synthetic data only. This is not a full import inventory, dynamic loader result, or compatibility percentage. Catalog device evidence is only evidence for independently tested candidates, not a license to replace imports. Source-level SwiftUI adapters do not satisfy these categories and are deliberately excluded. ABI documentation: https://github.com/swiftlang/swift/blob/main/docs/ABI/TypeMetadata.rst ; https://www.swift.org/blog/library-evolution/ . Future work should prioritize missing runtime entry points and actual dependency closure, not extrapolate successful source-level controls.
