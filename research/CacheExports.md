# Cache exports phase 3

Apple MachOAnalyzer.cpp getLinkeditLayout translates an offset by subtracting linkeditFileOffset and adding the segment's VM start; CacheLayout.md documents split segment layouts. The cache_exports tool reads an indexed image header, checks __TEXT identity, locates __LINKEDIT, maps the export trie range via UUID-matched cache parts, and reuses the bounded export decoder. It rejects missing/ambiguous mappings, out-of-segment offsets, and unsupported images. Example: python3 scripts/cache_exports.py --provider /usr/lib/swift/libswiftCore.dylib --symbol '_swift_getOpaqueTypeMetadata2' MAIN PART1 PART2 . No extraction, code execution, modification, pointer authentication manipulation or native absence inference. A complete metadata match is not cryptographic validation. ARM64e cache evidence must not be conflated with an ordinary ARM64 app ABI. Tests use synthetic split mappings only; original iOS 16.2 cache not yet verified. Previous cache set CI passed run 46045807448. Sources: https://github.com/apple-oss-distributions/dyld/blob/main/common/MachOAnalyzer.cpp and https://github.com/apple-oss-distributions/dyld/blob/main/doc/CacheLayout.md .
