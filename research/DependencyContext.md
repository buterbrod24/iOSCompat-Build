# Explicit executable-context dependency research

Apple dyld man page https://github.com/apple-oss-distributions/dyld/blob/main/doc/man/man1/dyld.1 describes executable-relative, loader-relative and inherited LC_RPATH paths. This current public source documents the general mechanism, not the exact iOS 16.2 dyld implementation. `dependency_context.py` consumes a local analyzer JSON report and an explicitly selected ordinary ARM64 executable path. Example: `python3 scripts/dependency_context.py report.json --root Payload/Test.app/Test --output graph.json`. It explores all observed local candidates in each inherited path context, with finite traversal budgets and cycle deduplication. Separate app-extension roots should be analyzed separately; other images are not proven unused. All dependency kinds remain labeled; no startup-order inference. No dyld execution, path modification, system cache access or binary patching. Eight synthetic controls.
