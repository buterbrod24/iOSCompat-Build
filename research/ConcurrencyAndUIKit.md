# Concurrency and UIKit: next compatibility research

## Swift stream factories
SE-0388 (https://github.com/swiftlang/swift-evolution/blob/main/proposals/0388-async-stream-factory.md) describes the two Swift 5.9 factories as additive APIs based on the older synchronous continuation initializer. Both are back-deployed by the compiler. Existing separately compiled clients may nevertheless import the newer native symbol when their minimum deployment permits it. The existing StreamCandidate follows the same public initializer pattern independently. New stream-backdeploy workflow measures stock object imports at iOS 16.2 and 17.0, -Onone and -O, without raising the caller availability to iOS 17. Results are compiler evidence only, not a retrofit of existing binaries. No raw SDK code or third-party application binaries are published.

## Executor
SE-0392 (https://github.com/swiftlang/swift-evolution/blob/main/proposals/0392-custom-actor-executors.md) describes consuming ExecutorJob and the legacy UnownedJob, plus exclusive execution-context comparison. SE-0424 (https://github.com/swiftlang/swift-evolution/blob/main/proposals/0424-custom-isolation-checking-for-serialexecutor.md) adds later isolation-checking support. Preserve exactly-once execution and executor identity. No blind job aliases, protocol witness substitutions, or unsupported isolation assertions are approved. Earlier custom serial executor tests are baseline controls rather than a replacement ABI.

## UIKit
Apple's WWDC23 trait system session (https://developer.apple.com/videos/play/wwdc2023/10057/) and https://developer.apple.com/documentation/uikit/adapting-your-app-when-traits-change explain the transition from traitCollectionDidChange to selective registration, new trait overrides, and hierarchy propagation. A source-level legacy observer can compare specific old/new trait values for appearance, horizontal/vertical size classes and Dynamic Type, with explicit initial state, registration lifetime, removal and MainActor behavior. It cannot provide native UITraitDefinition identity, existential witness tables, UITraitOverrides representation or arbitrary hierarchy semantics. A limited adapter is worth testing independently; binary integration remains separate. Never invent accessibility trait constants or report arbitrary missing APIs as successful no-ops.

## Priorities
First collect the already-built Array Probe 0.1.0 report, then evaluate the exact specialization lookup and ABI constraints. In parallel study stream factory compiler behavior. Focus on meaningful independently testable APIs, not fake exports. The previous Observation legacy reactive bridge CI is successful (run 46044333483); its source-level Combine bridge is not a native SwiftUI binary substitute. No system libraries modified.
