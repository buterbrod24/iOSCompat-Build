Blacktop IPSW documentation (https://blacktop.github.io/ipsw/docs/guides/dyld/ and https://github.com/blacktop/ipsw) provides independent cache metadata and firmware comparison tools. Use ipsw dyld info to cross-check supplied cache metadata. The new cache_compare tool creates local JSON snapshots of explicitly selected providers from metadata-matched iOS cache sets, recording UUID, platform, OS version, architecture, and trie status. Compare only same-architecture snapshots in ascending OS version order. Report newly observed entries, older-only entries, changed terminal metadata (including renamed exports and weak definitions), and changed whole-library reexport declarations. Missing or uninspected providers are not treated as empty. No new entry is automatically a missing runtime symbol: reexport reachability, image provenance and callable ABI require independent evidence. No cache content, firmware, or user application is published. The comparison tests use synthetic metadata; actual snapshot creation still requires real local cache files. Example: python3 scripts/cache_compare.py snapshot MAIN PART1 PART2 --provider /usr/lib/swift/libswiftCore.dylib > old.json ; repeat for newer OS to new.json ; python3 scripts/cache_compare.py compare old.json new.json .
