# SwiftUI ABI role research

Swift ABI Mangling.rst and TypeMetadata.rst describe structurally distinct callable functions, metadata accessors, type/protocol/conformance descriptors, witness tables and opaque type descriptors. The new local tool uses the compiler's expanded demangler tree, checks symbol identity and classifies only explicit known top-level nodes. Static wrappers require a known callable child. Unknown nodes remain unclassified. No descriptor fabrication, symbol aliasing, witness rewriting or native metadata substitution. Ordinary callable does not mean safe to adapt: inspect calling convention, generic requirements, ownership, return type identity and behavior separately. Use python3 scripts/swift_symbol_roles.py symbols.txt with a local text list. Public illustrative symbols are used for independent tests; no user app report is committed.
