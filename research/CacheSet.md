# Cache set phase 2

Previous cache inventory CI passed in run 46045646030. Apple dyld_cache_format.h defines 24-byte legacy and 56-byte modern subcache entries. DyldSharedCache.cpp uses the header extent relative to cacheSubType to select suffix-bearing records. The new tool accepts explicit local paths only: python3 scripts/cache_set.py MAIN PART1 PART2 . It compares declared UUIDs, architecture, known platform/OS metadata, expected unslid starts, overlapping mappings and image ownership. It does not open files based on suffix strings, assume .symbols is required for mapped exports, validate signatures, extract firmware, or infer export availability. Missing declarations or mappings remain unverified. Header layout and current checks are synthetic-fixture research pending comparison with original iOS 16.2 cache files. Sources: https://github.com/apple-oss-distributions/dyld/blob/main/include/mach-o/dyld_cache_format.h and https://github.com/apple-oss-distributions/dyld/blob/main/common/DyldSharedCache.cpp .
