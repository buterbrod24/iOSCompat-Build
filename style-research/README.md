# ShapeStyle resolution research

Apple ShapeStyle https://developer.apple.com/documentation/swiftui/shapestyle and resolve(in:) https://developer.apple.com/documentation/swiftui/shapestyle/resolve(in:) expose a Resolved associated type and environment-dependent resolution. AnyShapeStyle https://developer.apple.com/documentation/swiftui/anyshapestyle supplies existing type erasure; Color https://developer.apple.com/documentation/swiftui/color describes deferred color resolution. Text.foregroundStyle https://developer.apple.com/documentation/swiftui/text/foregroundstyle(_:) returns Text on the modern API, unlike a generic legacy View modifier. Stock.swift is an original modern SDK client for associated-type, conformance, generic dispatch, color and Text import observations. Independent legacy resolver accepts explicit environment values, returns AnyShapeStyle, and has opt-in view/shape adapters. Five host controls check forwarding and reevaluation, not actual resolved color equality or pixel output. Native protocol identity, witness layout, Color.Resolved layout, Text-preserving style, material rendering and arbitrary custom conformances are not implemented. No binary aliases or system changes.
