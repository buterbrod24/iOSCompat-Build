# Legacy menu actions

Apple WWDC23 https://developer.apple.com/videos/play/wwdc2023/10055/ explains custom selectedImage as a selection indicator; the older initializer https://developer.apple.com/documentation/uikit/uiaction/init(title:subtitle:image:identifier:discoverabilitytitle:attributes:state:handler:) preserves the ordinary image separately. CompatActionDescriptor explicitly reports the unavailable custom selection indicator rather than silently replacing the ordinary image. It constructs native legacy UIAction instances, passes the handler to UIKit, and preserves state/attributes/identifier/title/subtitle. A separate owner-managed single-selection model validates identifiers and disabled/hidden states. Twelve controls check descriptor properties and model behavior, not actual user interaction, menu rendering or invocation of the UIAction closure. No new UIKit protocol identity, binary alias, swizzling or claim that a compiled third-party app can use this adapter. Trait observer controls passed 10/10 in run 46046983706; the unavailable component has compiled for iOS 16.2, simulator results pending at this commit.
