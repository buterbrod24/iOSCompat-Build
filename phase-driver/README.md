# Integrated phase driver

Completion CI 46050083284 succeeded, 12/12 controls. Driver.swift connects the independently implemented phase sequence, cubic motion timeline and explicit completion group. It owns a single scalar track, samples from the current presentation value and velocity when retriggered, and acknowledges only its own finished segment. Cancellation freezes the sampled value with zero velocity. Monotonic supplied timestamps reject backwards and nonfinite input. At most one completed step is processed per tick, with no attempt to replay missed steps after a stall. This is a deliberate local policy, not native PhaseAnimator interruption or transaction behavior. No actual SwiftUI rendering, generic Animatable support, system hooks or native ABI substitution.
