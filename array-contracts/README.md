# Swift Core private array contracts

The previously validated reserveCapacity candidate is public-API based. The next group comprises internal mutation helpers, buffer consumption and slow-path indexing. Inspection of Swift 5.7 and 5.9 shows that endMutation terminates a COW mutation, appendElementAssumeUniqueAndCapacity writes into initialized-count-managed storage under uniqueness and capacity preconditions, and consumeAndCreateNew may move rather than copy reference elements. A public append/reserve call does not automatically implement those internal contracts. The audit compares source-level declarations, annotations and body hashes of 14 method contracts. This does not verify private buffer layout or specialized ABI. No aliases, stub exports or runtime replacement are produced. Future runtime lookup evidence and independent ownership controls are required before considering any candidate.
