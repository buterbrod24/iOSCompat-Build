# Observation scoped environment research

Apple Environment.init(_:) https://developer.apple.com/documentation/swiftui/environment/init(_:)-7pint and https://developer.apple.com/documentation/swiftui/environment describe type-keyed observable objects, required lookup failure, and optional lookup. Custom EnvironmentKey https://developer.apple.com/documentation/swiftui/environmentkey is available on legacy SwiftUI. The independent scope maps exact static type identity to objects, value-copies scopes, shadows by type, and supports explicit nil removal. Adapter uses a custom environment key, optional lookup and an explicitly tracked key-path projection through the existing CompatTrackedValue bridge. StateObject identity includes object identity and projection key path; model replacement resets the projection subtree. Local optional-only policy deliberately avoids fatal missing-object behavior. Projection reactivity is not automatic tracking of arbitrary View.body reads. All model access and writes must be MainActor confined. CI uses pinned upstream Swift Observation sources compiled into an isolated module, not the exact previously device-tested dylib; ten host checks cover scope and reactivity, plus iOS 16.2 compilation. Actual mounted view propagation and lifetime remain untested. No native Environment/Observable protocol substitution or ABI alias, no third-party binaries.
