# Motion playback device probe

Run 46049385691 passed 12/12 scalar, 10/10 spring, 10/10 motion controls and 9/9 native macOS linear sample comparisons, and compiled all three for arm64 iOS 16.2. Native cubic/spring parity remains unverified. Apple TimelineView documentation https://developer.apple.com/documentation/swiftui/timelineview and animation schedule https://developer.apple.com/documentation/swiftui/timelineschedule/animation(minimuminterval:paused:) specify scheduled redraws, not guaranteed frame rate. The original demonstration uses the legacy animation schedule and samples elapsed monotonic uptime, independent of frame count. Playback is manual, one-shot, and pauses on inactivity, disappearance or Reduce Motion. Ten deterministic playback controls can also run on the device. Visual smoothness, frame timing, actual gesture interactions and battery impact require manual testing. No native ABI replacement, third-party binaries, or system changes. Artifact pending CI.
