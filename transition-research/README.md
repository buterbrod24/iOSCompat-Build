# Transition ABI research

Apple documentation: https://developer.apple.com/documentation/swiftui/transition ; https://developer.apple.com/documentation/swiftui/anytransition/ ; https://developer.apple.com/documentation/swiftui/transitionphase . Modern Transition returns opaque types for combined(with:) and animation(_:), whereas legacy AnyTransition is a type-erased value with similar operations. Stock.swift is an original SDK client to observe exact modern function/descriptor imports and primitive constructors. Adapter.swift implements a separate explicit wrapper using public legacy AnyTransition. CI captures imports and selected LLVM IR lines and runs eight construction smoke checks. No type identity, native protocol replacement, rendering, animation timing, interruption, view identity or completion semantics are established. Custom arbitrary TransitionPhase bodies are not implemented. No user audit or third-party binaries committed.
