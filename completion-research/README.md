# Explicit animation completion

Apple Transaction.addAnimationCompletion (https://developer.apple.com/documentation/swiftui/transaction/addanimationcompletion(criteria:_:)) waits for all transaction animations. AnimationCompletionCriteria distinguishes logical completion and removal; logicallyComplete(after:) documents removal before duration reporting logical completion immediately. Core Animation CAAnimationDelegate.animationDidStop(_:finished:) is a separate API for animations owned by a layer driver, not a universal observer for SwiftUI. The independent MainActor group accepts explicitly registered track signals, seals registration, distinguishes logical and removal completion, reports cancellation separately, and delivers a terminal callback once, including empty groups. No assumption of Apple's interruption/cancellation behavior, no automatic SwiftUI transaction observation, no binary substitution. Twelve deterministic tests; iOS 16.2 compilation gate.
